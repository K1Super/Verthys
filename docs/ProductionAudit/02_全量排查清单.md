# Verthys 全量排查清单（检查项 · 排查路径 · 验证标准）

> 用法：本清单为**施工前逐条过、施工中逐条验**的作业指导书。
> 状态列：【已证实】= 本轮已取证；【待核验】= 须实测；【已排除】= 已判定非缺陷。
> 排查路径给出**可直接执行的命令或精确文件位置**；验证标准为**可判定的通过条件**（禁止模糊）。
> 优先级：P0（阻断）> P1（高）> P2（中）> P3（低）。
