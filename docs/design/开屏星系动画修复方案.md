## 一、设计总览（v4 两通道模型）

### 1.1 现行问题的一句话根因

v3 把"打断"建模为**两个序列的叠加**（intro 残余衰减 + enter 爬升），
其和必然出现"先跌后升"，其差（方向权重）必然出现"短窗穿轴"——**叠加
模型与打断语义不相容**；v4 改为**单一复合序列**：打断瞬间冻结锚点，
强度沿"抬升剖面"单调续走、方向以动量匹配换向曲线一次穿越零点后并入自然剖面。

### 1.2 复合强度 E：e0 提升曲线族

定义（x = enterClock / ENTER_T ∈ [0,1]，e0 = 打断时刻的 intro 包络值）：

```
E(x; e0) = e0 + (1 - e0) · warpEnvelope(x)      ,  x ≤ 0.62
E(x; e0) = warpEnvelope(x)                       ,  x > 0.62（消散段，不变）
```

`warpEnvelope` 为现行三段 smootherstep 剖面（0→0.42→1→0，[useTransitionEngine.ts](file:///c:/Users/Administrator/Desktop/Verthys/verthys-tauri/src/composables/useTransitionEngine.ts#L57-L66) 保持不变）。

**性质（全部经仿真验证，§五）**：
- 值域：E ∈ [e0, 1] —— 升档部分 ≤ e0+(1-e0)·1 = 1（实测全时刻 max=1.000000）；
- 单调不回退：rise 段单调升（系数 1-e0 ≥ 0），实测 ti 全扫描"回退量 = 0"
  —— **缺陷 01/10 结构性根除**；
- 同族连续：e0→0 时退化为自然剖面，2.99s 与 3.01s 点击无行为断点；
- C2 拼接：x=0.62 处两侧值 1 / 斜率 0 / 曲率 0 精确匹配（并入消散段）。

### 1.3 方向权重 D：单曲线动量匹配换向（打断路径）

打断瞬间冻结 `D0 = -e0` 与其一/二阶导（`D′0 = −E′intro(t_i)`、
`D″0 = −E″intro(t_i)`），此后由**单条二阶连续换向曲线**承载：

| 阶段 | 区间（自打断起，秒） | 曲线 | 语义 |
|---|---|---|---|
| 换向 | [0, 1.5) | `Hermite5(D0, D′0, D″0 → 并入点三量)` | 动量匹配起步，一次穿越零点（无驻停） |
| 自然剖面 | ≥1.5 | `warpEnvelope(t / ENTER_T)` | 与自然正渡完全同轨 |

**并入点取 x = 0.30 = 蓄能段平台点**：该处自然剖面的值 / 一阶 / 二阶为
（0.42, 0, 0）——换向曲线与自然剖面**三量精确相切**（接缝 C2，实测
一阶台阶 ≤1e-9）；e0→0 时换向曲线精确退化为蓄能段 smootherstep 本体
（同族连续）。实现按通用 Hermite 取并入点切线，`ENTER_T_MS` 被改动时
并入处依旧 C2 相切。

**性质（全部经仿真与单测验证）**：
- **动量连续**：换向曲线起点一阶导 = 来向速率（接缝无速率台阶，实测
  一致至 1e-6 量级）——**起点无顿挫**；
- **有界**：|D| ≤ 1 全程（动量前探上界实测 1.0000 — 不超全速）；
- **穿越为瞬态**：|D| ≤ 0.05 的贴零窗口 ≤ 0.2s（中段场景实测
  0.05–0.08s；旧三段走廊同场景 0.48–0.53s）——**中间停顿根除**；
- 穿越速率 ≤ 1.76/s（与逆渡峰值 1.65/s 同量级；旧实现穿轴甩动
  2.44/s）；相机随动 sway 峰值 ≤ 203.6 u/s（换向为真实运动，无驻停、
  无穿轴急扫）；
- 全时刻同一换向曲线（不按 e0 分档）—— 恒定路径，**缺陷 08 根除**。

### 1.4 连续性契约（v4 精确声明 — 收窄后）

- **值连续**：E / D 在全路径（自然 / 打断 / 接缝 / 交接）0 阶连续，零跳变；
- **段内与段间 C2**：包络三段、换向曲线、提升曲线并入消散段、换向
  曲线并入自然剖面 —— 值 / 一阶 / 二阶全匹配（解析证明 + 数值核验
  ≤1e-9）；
- **打断帧接续**：方向通道为**二阶连续**（值 / 一阶 / 二阶全匹配 —
  动量连续换向，无接缝台阶）；强度通道值连续，一阶为**有界台阶**
  = |E′intro(t_i)|（理论上界 **1.6447 s⁻¹** @ t≈2.43s；剖面驻留点
  0.9s / 1.86s 处为 0；实测各点见 §五表）。强度台阶为经证明的设计
  选择：精确斜率匹配与「值域受限 + 不回退」不可同时满足（附录 A），
  以有限台阶换取值域与不回退严格成立。

### 1.5 时序锚点统一（点击即锚）

- UnlockView 点击 → **同帧** `emit("enter")`（删除 320ms 魔法延迟）；
- 编排节点（PREWARM / PAGE_HANDOFF / GALAXY_PHASE）与引擎 enterClock
  全部自该时刻起算 —— **交接点 x=0.62 对任意打断时刻精确成立**
  （实测 E=D=1，偏差 ≤6.7e-6），materialize 1.9s 与消散段严格等长；
- 弹射（CSS，--ed 60–312ms 逐字延迟）与引擎蓄能同帧启动：弹射为点击
  主反馈（0.62s 内完成），蓄能段视觉平缓（1.5s 升至 0.42），不抢焦；
- constants 注记修正：PREWARM_MOUNT=1100 语义 = 逐字弹射最晚起始
  ≤312ms + 弹射 620ms + 余量 ≥168ms（点击锚点口径，与代码锚点一致）。

### 1.6 无障碍门控（reduced-motion）

- 引擎新增 `setReducedMotion(on)`：开启即跳过未完成的启动逆渡
  （introDone 置位）；`triggerEnter` 直接拒绝（正渡不产生大幅运动）；
- 编排压缩（仅 reduced 生效）：`TRANSITION_REDUCED = { PAGE_HANDOFF:
  1300, GALAXY_PHASE: 1500 }`（预挂载 1100 不变 —— 双缓冲时序保持）；
- 取景就位：reduced 下相机初始取景直接落在主界面目标（`phaseZ=760`），
  且相机取景阻尼系数取 1（状态切换零运镜）—— 消除 880→760 的 120
  单位全屏推拉；
- 页面淡变：`page-glitch` 0.45s 淡出 + `materialize` 在 reduced 下本就
  `transition:none`（[App.vue](file:///c:/Users/Administrator/Desktop/Verthys/verthys-tauri/src/App.vue#L163-L166) 既有规则）—— 全程无大幅运动。
- 说明：环境氛围（星系慢旋）为常态背景而非转场运动，维持现状（与
  闲置档位联动降频），不在本缺陷范围。

### 1.7 品牌软离场分级（缺陷 04）

CSS 动画被整体替换是硬切的根因；分级原则：**入场动画未完成的组，不
切换其离场动画，改为整组软淡出**（父级 transition 与子级入场动画叠加，
零跳变）；已完成组维持现行弹射 / 塌缩编排（3s 后自然点击观感不变）。

| 组 | 入场完成时刻（实测/hash 计算） | 门控常量 |
|---|---|---|
| `.brand-core`（逐字 + 谱线 + 副标题） | max(2068, 2700) = **2700ms** | `brandDoneAt`（运行时由参数场计算，防漂移） |
| `.orbit-filaments` | **3400ms**（最晚揭示 1.5s + 1.9s） | `FILS_DONE_AT` |
| `.enter-hint` | **4270ms**（浮现 3250 + 右线 120 + 生长 900） | `HINT_DONE_AT` |

副标题为 transition 驱动（非 animation），离场本就平滑，随组门控即可。

```ts
 * 复合渡越包络（归一化 x∈[0,1]，三段 smootherstep — 全程 C2 连续）：
 *   蓄能段 x<0.30：0 → 0.42 ／ 峰驻段 0.30≤x<0.62：0.42 → 1.0 ／
 *   消散段 x≥0.62：1.0 → 0（引力井松开 — 平滑释放）。
 */
const warpEnvelope = (x: number): number => {
  if (x <= 0 || x >= 1) return 0;
  if (x < ENV_CHARGE_END) return ENV_CHARGE_LEVEL * smootherstep(x / ENV_CHARGE_END);
  if (x < ENV_PEAK_END)
    return (
      ENV_CHARGE_LEVEL +
      (1 - ENV_CHARGE_LEVEL) * smootherstep((x - ENV_CHARGE_END) / (ENV_PEAK_END - ENV_CHARGE_END))
    );
  return 1 - smootherstep((x - ENV_PEAK_END) / (1 - ENV_PEAK_END));
};

/** 包络一阶/二阶导（对 x）—— 换向并入点的切线条件（C2 相切） */
const warpEnvelopeD = (x: number): [number, number] => {
  if (x <= 0 || x >= 1) return [0, 0];
  if (x < ENV_CHARGE_END) {
    const u = x / ENV_CHARGE_END;
    return [
      (ENV_CHARGE_LEVEL * smootherstepD1(u)) / ENV_CHARGE_END,
      (ENV_CHARGE_LEVEL * smootherstepD2(u)) / (ENV_CHARGE_END * ENV_CHARGE_END),
    ];
  }
  if (x < ENV_PEAK_END) {
    const w = ENV_PEAK_END - ENV_CHARGE_END;
    const u = (x - ENV_CHARGE_END) / w;
    return [
      ((1 - ENV_CHARGE_LEVEL) * smootherstepD1(u)) / w,
      ((1 - ENV_CHARGE_LEVEL) * smootherstepD2(u)) / (w * w),
    ];
  }
  const w = 1 - ENV_PEAK_END;
  const u = (x - ENV_PEAK_END) / w;
  return [-smootherstepD1(u) / w, -smootherstepD2(u) / (w * w)];
};

/** 五次 Hermite 插值（值/一阶/二阶双端匹配）—— 换向曲线 */
const hermite5 = (
  u: number,
  p0: number, v0: number, a0: number,
  p1: number, v1: number, a1: number,
  span: number,
): number => {
  const u2 = u * u;
  const u3 = u2 * u;
  const u4 = u3 * u;
  const u5 = u4 * u;
  return (
    (1 - 10 * u3 + 15 * u4 - 6 * u5) * p0 +
    (u - 6 * u3 + 8 * u4 - 3 * u5) * span * v0 +
    (0.5 * u2 - 1.5 * u3 + 1.5 * u4 - 0.5 * u5) * span * span * a0 +
    (10 * u3 - 15 * u4 + 6 * u5) * p1 +
    (-4 * u3 + 7 * u4 - 3 * u5) * span * v1 +
    (0.5 * u3 - u4 + 0.5 * u5) * span * span * a1
  );
};

/** 换向并入相位（正渡 5000ms 下为 0.30 — 恰为蓄能段平台点） */
const REVERSAL_JOIN_X = REVERSAL_T / ENTER_T;
/** 并入点自然剖面的值/一阶/二阶（每秒制）— 平台点处为（0.42, 0, 0） */
const REVERSAL_JOIN_D = warpEnvelope(REVERSAL_JOIN_X);
const REVERSAL_JOIN_V = warpEnvelopeD(REVERSAL_JOIN_X)[0] / ENTER_T;
const REVERSAL_JOIN_A = warpEnvelopeD(REVERSAL_JOIN_X)[1] / (ENTER_T * ENTER_T);

/* ===== 积分历史采样器（环形缓冲 + 二分插值 — 与 v3 完全一致） =====
 * 单调积分（渡越弧长）采样近期的 (t, v)；残影拖尾层按 t-lag 插值取
 * 历史值 → 弧形拖尾（早于最早样本 → 0：运动开始前 — 语义保持）。
 * 时间戳单调递增 → 二分查找 O(log n)；预分配 Float32Array 环形覆盖
 * 写入 → O(1) 零分配（无每帧 push/shift）。 */
const HIST_CAPACITY = 64;

const createIntegralHistory = () => {
  const ts = new Float32Array(HIST_CAPACITY);
  const vs = new Float32Array(HIST_CAPACITY);
  let head = -1;
  let count = 0;

  const oldestIndex = (): number => (head - count + 1 + HIST_CAPACITY) % HIST_CAPACITY;

  return {
    push(t: number, v: number): void {
      head = (head + 1) % HIST_CAPACITY;
      ts[head] = t;
      vs[head] = v;
      if (count < HIST_CAPACITY) count++;
    },
    at(time: number): number {
      if (count === 0) return 0;
      const oldest = oldestIndex();
      if (time <= ts[oldest]) return 0;

      let lo = 0;
      let hi = count;
      while (lo < hi) {
        const mid = (lo + hi) >> 1;
        if (ts[(oldest + mid) % HIST_CAPACITY] <= time) {
          lo = mid + 1;
        } else {
          hi = mid;
        }
      }
      if (lo >= count) return vs[head];

      const idxN = (oldest + lo) % HIST_CAPACITY;
      const idxS = (oldest + lo - 1 + HIST_CAPACITY) % HIST_CAPACITY;
      const span = ts[idxN] - ts[idxS];
      if (span <= 0) return vs[idxN];
      return vs[idxS] + (vs[idxN] - vs[idxS]) * ((time - ts[idxS]) / span);
    },
  };
};

/**
 * 方向性渡越序列引擎（单实例 — 随 ParticleBackground 生命周期）
 *
 * 时钟纪律：所有时钟无条件单调推进，绝不冻结；效果生效与否由
 * done 标志独立守卫。
 */
export class TransitionEngine {
  /* 渲染域时钟（秒 — 与门控 dt 同基准，跳帧慢放语义统一） */
  private clock = 0;
  /* intro：启动即播放（设计行为 — 星系倒卷成型全屏逆渡） */
  private introClock = 0;
  private introInterruptedAt: number | null = null;
  private introDone = false;
  /* enter：点击进入触发（triggerEnter） */
  private enterClock: number | null = null;
  /* 打断锚点（触发时刻冻结）：抬升剖面起点强度 / 换向起点方向量与其
   * 一/二阶导（动量匹配 — 接缝二阶连续） */
  private launchedLevel = 0;
  private launchedDir = 0;
  private launchedDirV = 0;
  private launchedDirA = 0;
  /* 无障碍：prefers-reduced-motion — 逆渡跳过、正渡停用（无大幅运动） */
  private reducedMotion = false;

  private warpEnvVal = 0;
  private dirWVal = 0;
  private warpDistVal = 0;
  private swirlVal = 0;
  private history = createIntegralHistory();

  /** 无障碍门控（幂等）：开启且逆渡尚未结束时跳过逆渡；正渡由 triggerEnter 拒绝。
   *  中途开启：不追溯打断进行中的进入序列（避免跳变）；关闭不重放逆渡。 */
  setReducedMotion(on: boolean): void {
    this.reducedMotion = on;
    if (on && !this.introDone && this.introInterruptedAt === null && this.enterClock === null) {
      this.introDone = true;
    }
  }

  /**
   * 推进一帧：双时间参数
   *   - frameStep（钳制帧步进）：物理积分专用（缠绕/幕布位移）；
   *   - wallStep（墙钟增量）：进度计算专用（时钟/复合序列），不钳制 —
   *     低档位下包络推进与静止漂移速度不随帧率失真。
   * 时钟无条件推进，返回渲染域时钟（秒）。
   */
  update(frameStep: number, wallStep: number): number {
    this.clock += wallStep;
    this.introClock += wallStep;
    if (this.enterClock !== null) this.enterClock += wallStep;

    let env = 0;
    let dir = 0;

    /* 1) 启动逆渡（自然路径：未点击、未打断、未降级） */
    if (!this.introDone && this.introInterruptedAt === null) {
      if (this.introClock >= INTRO_T) {
        this.introDone = true; // 逆渡自然完成（未被点击打断）
      } else {
        env = warpEnvelope(this.introClock / INTRO_T);
        dir = -env;
      }
    }

    /* 2) 进入正渡：自然（3s 后点击）/ 打断（3s 内点击）两条路径 */
    if (this.enterClock !== null) {
      const x = this.enterClock / ENTER_T;
      if (this.introInterruptedAt === null) {
        const e = warpEnvelope(x);
        env = e;
        dir = e; // 自然正渡：强度与方向同剖面
      } else {
        env = this.launchedEnvelope(x);
        dir = this.launchedDirection(this.enterClock);
      }
    }

    /* 合成场强度（收缩/噪声/拖尾/FOV/Z 冲程）与符号方向权重（缠绕/相机方向） */
    this.warpEnvVal = env;
    this.dirWVal = dir;
    /* uWarpDist 为符号积分（远景幕布跟随序列方向漂移）——物理积分用帧步进 */
    this.warpDistVal += dir * WARP_SPEED * frameStep;
    /* 符号缠绕积分：正渡正向缠绕、逆渡反向倒卷，角度恒连续（积分量） */
    this.swirlVal += dir * frameStep;
    this.history.push(this.clock, this.swirlVal);
    return this.clock;
  }

  /** 点击进入：正渡自零启动；逆渡进行中则冻结打断锚点（提升曲线 +
   *  换向曲线起点）。幂等守卫：正渡进行中重复触发直接忽略（防重放跳变）。 */
  triggerEnter(): void {
    if (this.reducedMotion) return; // 无障碍：正渡停用（无大幅运动）
    if (this.enterClock !== null) return; // 幂等守卫
    if (!this.introDone) {
      this.introDone = true;
      this.introInterruptedAt = this.introClock;
      const x = this.introClock / INTRO_T;
      const [d1, d2] = warpEnvelopeD(x);
      this.launchedLevel = warpEnvelope(x);
      this.launchedDir = -this.launchedLevel;
      /* 动量匹配：换向曲线起点一/二阶导 = 来向斜率（每秒制） */
      this.launchedDirV = -d1 / INTRO_T;
      this.launchedDirA = -d2 / (INTRO_T * INTRO_T);
    }
    this.enterClock = 0;
  }

  /** 提升曲线：e0 处抬升的自然剖面（x≤0.62 单调升档至 1，其后同消散段） */
  private launchedEnvelope(x: number): number {
    return x <= ENV_PEAK_END
      ? this.launchedLevel + (1 - this.launchedLevel) * warpEnvelope(x)
      : warpEnvelope(x);
  }

  /** 换向曲线：单条二阶连续曲线 —— 以打断瞬间的方向量与其一/二阶导为
   *  起点（动量匹配，接缝无速率台阶）、以自然剖面平台点为终点（值/
   *  一阶/二阶三量匹配），窗口内一次穿越零点（无驻停段）；窗口结束后
   *  并入自然剖面。 */
  private launchedDirection(tc: number): number {
    if (tc < REVERSAL_T) {
      return hermite5(
        tc / REVERSAL_T,
        this.launchedDir,
        this.launchedDirV,
        this.launchedDirA,
        REVERSAL_JOIN_D,
        REVERSAL_JOIN_V,
        REVERSAL_JOIN_A,
        REVERSAL_T,
      );
    }
    return warpEnvelope(tc / ENTER_T);
  }

  /** t 时刻缠绕积分采样（残影拖尾历史值 — 早于首样本 → 0：运动开始前） */
  swirlAt(t: number): number {
    return this.history.at(t);
  }

  /** 渲染域时钟（秒）— 粒子轨道/相机漂移/呼吸项统一时间基准 */
  get time(): number {
    return this.clock;
  }
  /** 合成渡越场强度（0-1） */
  get warpEnv(): number {
    return this.warpEnvVal;
  }
  /** 符号方向权重（enter − intro ∈ [-1,1]） */
  get dirW(): number {
    return this.dirWVal;
  }
  /** 幕布位移积分（符号 — 驱动远景着色器环绕推进） */
  get warpDist(): number {
    return this.warpDistVal;
  }
  /** 当前符号缠绕积分（正渡 +/逆渡 −） */
  get swirl(): number {
    return this.swirlVal;
  }
}

/** 组合式入口：组件内创建引擎实例（每组件实例独立，随卸载废弃） */
export function useTransitionEngine(): TransitionEngine {
  return new TransitionEngine();
}
```

**实施注意（防错清单）**：
1. `launchedEnvelope` **不得**对 `x≤0` 提前返回 0 —— x=0 帧须返回 e0
   （公式天然成立：`e0 + (1-e0)·warpEnvelope(0)` = e0）；仅 `warpEnvelope`
   自身处理边界。
2. `warpEnvelopeD` 分支次序须与 `warpEnvelope` 严格一致（`x < 0.3` /
   `x < 0.62` / else）；x=0.30 落在第二分支且 u=0 → 返回 (0,0) ——
   并入点切线 (0.42, 0, 0) 精确成立（这是"平台点并入"的关键）。
3. `triggerEnter` 守卫次序：reduced → 幂等 → 打断锚点 → 启动；不得调换。

## 附录 A：接缝斜率匹配的权衡分析（缺陷 06 处置依据）

该权衡适用于**强度通道**：其受值域受限（E∈[0,1]）与不回退约束，且
去程斜率 v0 可正可负（末段点击时逆渡正在释放）—— 精确匹配 v0 会迫使
曲线过冲或产生加速度尖峰，故强度通道冻结为有界台阶。方向通道不受此
约束（其允许值域内的动量前探）：现行换向曲线以（值/一阶/二阶）三量
与来向精确匹配起步，动量前探实测严格 ≤1（不超全速），零点穿越为
单次运动穿过 —— 接缝无台阶（见 §5.4）。

设接续窗口 T 内曲线 p(t) 需满足：值域受限（E∈[0,1]）、不回退（E）、
有界高阶光滑（|p″| 有界），且在 t=0 与来向一阶导 v0 ≠ 0 相接。由
`∫₀ᵀ p′ dt = Δp`（净位移受值域约束有界）：若令 p′(0) = v0，当
|v0|·T 与 Δp 相容区间不匹配时，p′ 必须 ①在窗口内变号（⇒ 过冲，可能
越界），或 ②以极短时间归零（⇒ 加速度尖峰，高阶不光滑）。三者不可
同时满足。

本方案在强度通道选取的操作点：**放弃精确斜率匹配**，冻结为有界台阶
（≤1.6447 s⁻¹，且与点击时刻相关、驻留点为零），换取：E 严格不回退、
值域严格成立、全路径高阶光滑。v3 同样存在该台阶（且与深谷、甩动
叠加）；现行实现将其独立保留为唯一且可量化的残差。
