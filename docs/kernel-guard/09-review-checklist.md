## 2. 逐文档审核

### 2.1 README

- [ ] 范围限定为 L1，不包含 L2/L3
- [ ] 冻结决策 13 条无异议
- [ ] 审核门禁明确“未通过不编码”
- [ ] 文档索引与实际文件一致

### 2.2 威胁模型

- [ ] 防护对象与资产清单完整
- [ ] 信任边界与组件职责一致
- [ ] 同用户攻击路径覆盖读内存、注入、终止、挂起、调试、Dump
- [ ] 管理员/内核/离线攻击明确不覆盖
- [ ] 残余风险 R1–R10 可接受
- [ ] 安全声明边界无夸大

### 2.3 总体架构

- [ ] 驱动只由 SYSTEM 服务访问
- [ ] 驱动不进入数据面
- [ ] 启动顺序先 ARM 映像路径，消除外部危险句柄窗口
- [ ] worker 重启、运行中丢失、卸载路径闭合
- [ ] 状态机与失败语义一致
- [ ] 与现有 P2 服务、预设流程不冲突
- [ ] 不新增第 12 个特性位

### 2.4 驱动设计

- [ ] KMDF 非 PnP、设备 ACL、IOCTL 版本/长度校验合理
- [ ] 受保护进程身份 = 进程对象 + 创建时间 + 映像路径
- [ ] 进程/线程权限剥离清单合理
- [ ] 可信服务保留查询/终止能力
- [ ] 既有句柄不可追溯的限制已写明
- [ ] 回调内不做阻塞/分配/日志
- [ ] 卸载与在途回调处理安全
- [ ] Ob 回调在驱动加载时注册，未 ARM 时直接放行，不在切档时反复注册/注销
- [ ] HVCI/Driver Verifier 兼容要求明确

### 2.5 服务与档位策略

- [ ] 三档 + 自定义不变，无第四个预设
- [ ] `SECURE` 默认 `preferred`；`required` 为高级选项
- [ ] 解锁前不可用的降级/fail-closed 语义正确
- [ ] 运行期切档事务与回滚正确
- [ ] 运行中丢失立即锁定
- [ ] UI 状态与文案不误导
- [ ] 审计字段不包含敏感信息
- [ ] `preset.json` 可被改写的问题与 K2 前置条件明确

### 2.6 测试与验证

- [ ] 无驱动环境全量回归是默认门禁
- [ ] 攻击回归 A1–A15 覆盖主要路径
- [ ] 状态用例 S1–S12 覆盖失败语义
- [ ] VM 测试签名/生产签名环境分离
- [ ] Driver Verifier、HVCI、Secure Boot、AV/EDR 纳入门禁
- [ ] 证据格式可复现
- [ ] 测试钩子不进生产

### 2.7 构建、签名与发布

- [ ] WDK/SDK/VS 版本路线可执行
- [ ] WDK 环境验证记录已确认（SDK/WDK 28000、64 位 MSBuild、KMDF 冒烟）
- [ ] 独立构建不影响现有发布链
- [ ] 测试签名与生产签名边界清楚
- [ ] EV + attestation 路线正确
- [ ] 安装/升级/回滚/卸载闭合
- [ ] K3 minifilter 认证路径标记为待确认

### 2.8 运维与维护

- [ ] 责任角色明确
- [ ] 事件/指标/审计可支撑定位
- [ ] 事故响应先止损后根因
- [ ] 兼容矩阵可执行
- [ ] 变更控制四项判据明确
- [ ] 降级/移除不损坏用户数据

### 2.9 路线图与 ADR

- [ ] K0–K4 边界清楚
- [ ] K1 只做 worker 句柄保护
- [ ] K3 条件启动，K4 不承诺
- [ ] ADR 状态与决策记录一致
- [ ] 代码量预算可接受
- [ ] 开放问题有默认建议

## 4. 阻断项

以下任一存在，不得进入编码：

- [ ] 威胁模型与实现范围不一致
- [ ] 驱动被设计为数据面/密钥托管
- [ ] 应用可直接访问驱动
- [ ] 新增第 12 个特性位或改变 11 位契约
- [ ] `SECURE` 在不可用时静默降级且 UI 不显示
- [ ] 运行中保护丢失不锁定
- [ ] 生产构建可能包含测试钩子/测试证书
- [ ] 无驱动环境回归路径不完整
- [ ] `required` 无恢复路径
- [ ] 签名路线不可执行
- [ ] 现有 P2 语义被无意修改

## 6. K0 通过后的第一步

K0 通过后只允许：

1. 创建 `kernel/` 工程骨架与 WDK 构建脚本
2. 创建 `vtg_protocol.h` 与用户态协议测试
3. 实现驱动加载/卸载/设备/IOCTL Ping
4. 不实现句柄权限剥离，直到 Ob 回调设计与安全评审通过

K1 编码仍按 [05-test-and-verification.md](05-test-and-verification.md) 门禁推进，不跳步。
