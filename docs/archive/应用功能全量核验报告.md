## 2. 核验方法与证据链

四层链路逐级核验，每一层都要求"上一层真实调用下一层"：

```
前端组件/Composable（invoke 命令）
    → Rust #[tauri::command]（spawn worker / 发 op）
        → verthys-worker dispatch.rs（op 分发）
            → C DLL 导出函数（FFI 调用）
                → 安全能力实现（生产路径调用点）
```
